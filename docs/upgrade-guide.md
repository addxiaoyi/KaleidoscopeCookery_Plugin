# SenLuo 五插件升级与回滚指南（开发版）

升级前停止服务器，备份世界、`plugins/` 和 `plugins/CraftEngine/resources/`。保留备份目录名中的时间和旧版本号，避免把新 schema 写回旧备份。

升级顺序：

1. 先替换 CraftEngine 到目标兼容版本并确认可回滚；开发基线固定为 26.9.1。
2. 替换需要更新的插件 JAR 和对应模块 CE 包。没有更新的模块保持原 JAR/包，不要把五个包强制合并。
3. 启动后先检查 `INSTALL-MANIFEST.json`、插件版本和 CE 加载日志，再进行玩家操作。加工、抽奖、酿造中的状态应在停机前自然保存。
4. 出现未知 schema、模型或配方错误时停止继续操作，保留日志和原始数据，回滚整组 JAR/CE 包与备份世界。

版本化存档读取遵循 `namespace/schema/source/payload` 信封：旧版本只执行显式迁移；未知版本或坏数据阻止操作并保留原数据，不当作空库存。跨模块联动插件可以缺失，但不能因此删除另一个模块的存档。

回滚时使用同一份世界备份和对应的五插件组合。不要只回滚 JAR 而保留已经写入的新数据格式；如果升级过程被中断，先恢复备份再启动旧版本。
