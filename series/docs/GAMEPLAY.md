# 本轮玩法与操作

2026-11-05，`0.1.0-dev-gameplay`。以下为代码已实现的开发版交互，均待测试服和原版客户端验收。目标仍为纯插件＋CraftEngine内容包；编译基线为Paper 1.21.11、Java 21、CraftEngine API 26.9.1。

## 玩偶

手持玩偶，潜行右键开始蓄力，松开投掷。5 tick起有效，35 tick达到速度上限。投出成功才扣一个物品，创造不扣。落地有衰减弹跳；飞行时可击退允许受影响的实体。直接攻击移动玩偶回收，背包满时保留实体。

手持玩偶右键实体，将玩偶作为乘客放到目标上；叠层有上限。这不是玩家骑玩偶。蓄力时换槽、换手、丢弃和背包移动被阻止；退出、死亡、传送取消蓄力。投掷和回收保留原物品元数据，临时使用动画组件在释放/取消时还原。

幻翼默认有3%概率延迟5 tick生成携带玩偶，同一只幻翼只判定一次。脱离坐骑后，默认累计3600个已加载tick消失。设置位于 `plugins/KaleidoscopeDollPlugin/config.yml`，包括投掷、粒子、击退、骑乘和幻翼开关。

实现采用原版隐形小盔甲架承载头部模型，并按实体所属区域调度。碰撞、朝向、流体表现和模组实体不同；移动玩偶尚未整合九轴微调、手持物独立变换或自定义Bedrock玩偶。没有每tick全世界扫描，但每个已加载移动玩偶有自己的tick任务，实际密度开销仍需压测。

## 葡萄

`/ktavern kit`包含藤架和葡萄藤。在藤架下方准备土壤，再手持葡萄藤右键藤架：泥土标签生成普通葡萄，冰或雪块生成冰葡萄，下界岩或岩浆块生成金葡萄。

- 藤龄0–3，果龄0–5。骨粉促进当前成长；成熟果实用剪刀采收3个对应葡萄，并有30%概率额外获得1–2个青提。
- 潜行用剪刀移除整条藤并返还葡萄藤。未成熟果实普通剪刀点击只提示；种植中的藤架不能直接拆除。
- 空藤架可用蜜脾封蜡阻止种植/扩散，用斧除蜡。
- 蔓延优先向上，再东、西、南、北；横向扩散直接使用成熟藤。只进入同所有者的空藤架，扩散还要求在线操作者处于可访问区域并通过保护校验。
- 下方为空气才生成虚拟果实。自然成长按68 tick错峰检查，概率按randomTickSpeed换算；设为0可暂停自然成长。冰葡萄低温、金葡萄高温提高成长概率。

这是已加载家具的概率模拟。果实成长优先，尚未复刻上游藤和果独立随机刻、架体连接、真实果实方块和野葡萄世界生成。

## 龙头和放置容器

龙头背面相邻格放来源，正下方一格放 `empty_bottle`。右键开启，30 tick后提取一次；再次右键可在完成前关闭。装满的瓶子用一个同类空瓶交换领取成品，放置的瓶子保留。满瓶保存完整物品，不能直接拆除。

| 来源 | 取出物 | 来源变化 |
| --- | --- | --- |
| 已发酵酒桶 | 该批次酒，保留熟成品质 | 成功后扣一份 |
| 西瓜 | 西瓜汁 | 不消耗西瓜 |
| 龙头方块（Dragon Head） | 原版龙息 | 不消耗头 |
| 蜂箱/蜂巢 | 原版蜂蜜瓶 | 每瓶减一级蜂蜜，0级不可取 |
| 水炼药锅、含水方块 | 原版水药水（WATER） | 不消耗源 |
| 岩浆炼药锅 | 燃烧瓶物品 | 不消耗源，投掷玩法尚未移植 |

水、蜂蜜、龙息用上游放置方块模型显示，领取时是对应原版物品。水来源也可填满下方的空/未满水炼药锅；岩浆来源复制到空炼药锅需显式打开酒馆配置 `tap.infinite-lava`，默认关闭。炼药锅填充发出可取消的Bukkit事件。

红石上升沿触发一次提取，记录的放置者/最后操作者必须在线。开始和完成时都检查来源、目的地和领地权限；在Folia上还要求相关区块与操作者由当前区域线程拥有，跨区域时跳过。区块卸载中止未完成提取，不预扣酒。索引只含已加载家具，不主动加载区块，不空闲轮询红石。

## 手持调酒

1. 在放置雪克杯中投入三份原料，酒类要求熟成至少4级；投料时返还原液体容器。
2. 手持一个空雪克杯，潜行右键已装料的雪克杯，将内容交换到手中。两边都有内容时拒绝交换。
3. 持续右键摇杯，松开结算。少于19 tick保留原料；19–68迷之酒，69–88特调，89–98尝试配方，99起迷之酒；111 tick自动结束。
4. 对放置的空鸡尾酒杯右键倒酒，再手持同类空杯交换领取。也可以潜行右键空雪克杯放回内容，或潜行右键方块重新放置手持杯。

原放置雪克杯的空手开始/再次停止操作继续支持。原料、成品和完整元数据保存在物品PDC与家具存档；内容变化同时更新CE拆除掉落的sourceItem。支付前预编码，编码错误不会先扣材料。取酒后拆装不会恢复旧原料。

使用原版饮用动作替代专用手部动画，尚无混色渲染。松手事件、CE放置优先级、死亡/传送/退出及Folia停用清理时序需要运行验收。

## Deco状态与染色

`/kdeco`内可领取状态工具，领取权限默认OP。工具及物品/标签/潜行条件按已导入规则触发状态切换；沙发额外支持16色染料、水桶清色及工具循环single/left/right/middle四种形态。同色不重复扣染料，创造不扣，清色不消耗水桶。

当前785家具条目中导出了102条状态转换、517条非pending交互规则（包含纯音效）、68种沙发颜色/形态组合。状态和颜色写入家具及掉落物，拆装保留。未匹配交互返回PASS给CE原生座位流程；需要额外脚本的事件明确提示尚未移植。

这些数字不是完整玩法数量。库存家具、椅垫、酒柜、overlay合并、自动相邻连接、精确座位/碰撞与剩余脚本继续见移植矩阵及 `deco-import.json`。资源验证只证明静态引用一致，不能证明CE实服加载及渲染成功。
